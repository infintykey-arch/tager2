# فهرس الاختبارات

**المجلد:** `test/` — اختبارات سلوك الوحدات وواجهات Flutter والتخزين المحلي والإقلاع.

## حسب المجال

- `test/widget_test.dart` — اختبار واجهة/تطبيق أساسي.
- `test/startup/` — اختبار بدء التشغيل السريع (`startup_smoke_test.dart`).
- `test/core/ads/` — اختبارات إعداد الإعلانات.
- `test/data/local/` — اختبار بقاء البيانات المحلية عبر فتح القاعدة.
- `test/features/analytics/` — تقارير ومستودع التحليلات وواجهته.
- `test/features/backup/` — تصدير واستعادة قاعدة البيانات.
- `test/features/calculator/` — محرك الآلة الحاسبة والواجهة.
- `test/features/debts/` — مسار واجهة الديون.
- `test/features/expenses/` — مستودع المصروفات ومسار الواجهة.
- `test/features/notes/` — مستودع الملاحظات والواجهة.
- `test/features/ocr/` و`test/features/pdf/` — خدمة OCR وإنشاء PDF.
- `test/features/products/` — البحث والمستودع والترحيل والأداء والترقيم وواجهة أسماء المنتجات الطويلة.
- `test/features/purchases/` — المستودع ومسار الشراء وتغييرات تكلفة المخزون القديمة.
- `test/features/sales/` — البيع وحساب متوسط التكلفة ومسار الفاتورة.
- `test/features/scanner/` — مسح الكود وربطه بالسلة/المنتج.
- `test/features/settings/` — مظهر التطبيق.

لتشغيل المجموعة كاملة من جذر المشروع: `flutter test`. عند تعديل ميزة، ابدأ باختبارات مجلدها؛ وعند تغيير قاعدة البيانات أو نقطة التشغيل شغّل اختبارات الترحيل/التخزين والإقلاع أيضًا.
