# فهرس اختبارات الميزات

الاختبارات في هذا المجلد مرتبة تحت `features/<اسم الميزة>/` لتقابل غالبًا `lib/features/<اسم الميزة>/`. لكل ملف، افتح فهرس الميزة في الكود من [`lib/features/CODE_INDEX.md`](../../lib/features/CODE_INDEX.md).

راجع [`../CODE_INDEX.md`](../CODE_INDEX.md) للحصول على خريطة مجموعات الاختبار وأسماء الملفات الموجودة. مجلد اختبار قد لا يوجد لكل ميزة؛ لا تفترض وجود تغطية لمجرد وجود وحدة في التطبيق.
