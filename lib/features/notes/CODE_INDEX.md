# فهرس ميزة الملاحظات

**المجلد:** `lib/features/notes/`

**الدور:** حفظ الملاحظات المحلية وعرضها وتحريرها وإغلاقها.

## الملفات

- [`data/notes_repository.dart`](data/notes_repository.dart) — نموذج الملاحظة وعمليات قاعدة البيانات الخاصة بها.
- [`presentation/notes_page.dart`](presentation/notes_page.dart) — قائمة الملاحظات وإضافة/تعديل الملاحظة وإجراءاتها.

## من أين أبدأ التعديل؟

- تغيير الشاشة أو التفاعل: ابدأ من مجلد `presentation/` في هذه الوحدة.
- تغيير القراءة أو الكتابة أو تكامل المنصة: ابدأ من مجلد `data/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
