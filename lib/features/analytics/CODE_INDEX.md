# فهرس ميزة التقارير والتحليلات

**المجلد:** `lib/features/analytics/`

**الدور:** جمع وعرض مؤشرات النشاط المحلي وتقارير المبيعات والمشتريات والمصروفات والديون والمخزون، مع فتح تفاصيل الفواتير وتصديرها عند الحاجة.

## الملفات

- [`data/report_repository.dart`](data/report_repository.dart) — مصدر بيانات التقارير وملخصاتها؛ يقرأ من قاعدة البيانات ومستودعات البيع والشراء.
- [`presentation/analysis_overview_page.dart`](presentation/analysis_overview_page.dart) — واجهة الملخص التحليلي والمؤشرات السريعة.
- [`presentation/analytics_page.dart`](presentation/analytics_page.dart) — واجهة التقارير التفصيلية، اختيار الفترة والنوع، واستعراض الفواتير والتفاصيل.

## من أين أبدأ التعديل؟

- تغيير الشاشة أو التفاعل: ابدأ من مجلد `presentation/` في هذه الوحدة.
- تغيير القراءة أو الكتابة أو تكامل المنصة: ابدأ من مجلد `data/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
