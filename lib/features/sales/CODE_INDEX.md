# فهرس ميزة المبيعات

**المجلد:** `lib/features/sales/`

**الدور:** إعداد فاتورة بيع وبنود السلة وتسجيلها محليًا مع بيانات الدفع.

## الملفات

- [`data/sales_repository.dart`](data/sales_repository.dart) — نماذج الفاتورة وبنودها والإيصالات وعمليات حفظ البيع والدفع.
- [`domain/sale_cart_line.dart`](domain/sale_cart_line.dart) — تمثيل بند المنتج والكمية والسعر داخل سلة البيع.
- [`presentation/sales_invoice_sheet.dart`](presentation/sales_invoice_sheet.dart) — واجهة إنشاء فاتورة البيع وعرض البنود والإجمالي.

## من أين أبدأ التعديل؟

- تغيير الشاشة أو التفاعل: ابدأ من مجلد `presentation/` في هذه الوحدة.
- تغيير نموذج أو قاعدة عمل: ابدأ من مجلد `domain/` في هذه الوحدة.
- تغيير القراءة أو الكتابة أو تكامل المنصة: ابدأ من مجلد `data/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
