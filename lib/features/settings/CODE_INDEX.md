# فهرس ميزة الإعدادات

**المجلد:** `lib/features/settings/`

**الدور:** قراءة وحفظ تفضيلات التطبيق المحلية.

## الملفات

- [`data/app_settings_repository.dart`](data/app_settings_repository.dart) — واجهة إعدادات التطبيق المطبقة على قاعدة Drift، ومنها تفضيلات المظهر.

## من أين أبدأ التعديل؟

- تغيير القراءة أو الكتابة أو تكامل المنصة: ابدأ من مجلد `data/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
