# فهرس ميزة إنشاء PDF

**المجلد:** `lib/features/pdf/`

**الدور:** إنشاء مستندات PDF محلية مستخدمة من مسارات الفواتير والتقارير.

## الملفات

- [`data/invoice_pdf_service.dart`](data/invoice_pdf_service.dart) — تجهيز مستندات PDF ومصادر الخطوط ومحتوى المستندات من بيانات الفواتير والتقارير.

## من أين أبدأ التعديل؟

- تغيير القراءة أو الكتابة أو تكامل المنصة: ابدأ من مجلد `data/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
