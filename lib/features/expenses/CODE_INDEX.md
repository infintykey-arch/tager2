# فهرس ميزة المصروفات

**المجلد:** `lib/features/expenses/`

**الدور:** حفظ المصروفات المحلية وعرضها وتعديلها مع ملخص إجمالي.

## الملفات

- [`data/expenses_repository.dart`](data/expenses_repository.dart) — نماذج إدخال المصروفات وواجهات قراءة/كتابة بياناتها في قاعدة Drift.
- [`presentation/expenses_page.dart`](presentation/expenses_page.dart) — قائمة المصروفات، الملخص، ونموذج إضافة/تعديل المصروف.

## من أين أبدأ التعديل؟

- تغيير الشاشة أو التفاعل: ابدأ من مجلد `presentation/` في هذه الوحدة.
- تغيير القراءة أو الكتابة أو تكامل المنصة: ابدأ من مجلد `data/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
