# فهرس ميزة النسخ الاحتياطي والاستعادة

**المجلد:** `lib/features/backup/`

**الدور:** تصدير بيانات قاعدة المحل محليًا واستيراد نسخة احتياطية والتحقق منها قبل استبدال البيانات الحالية.

## الملفات

- [`data/database_backup_repository.dart`](data/database_backup_repository.dart) — تجميع بيانات قاعدة البيانات في نسخة احتياطية وقراءة/فحص محتوى النسخة عند الاستعادة.
- [`presentation/backup_page.dart`](presentation/backup_page.dart) — واجهة اختيار ملف النسخة الاحتياطية، التصدير، والاستعادة.

## من أين أبدأ التعديل؟

- تغيير الشاشة أو التفاعل: ابدأ من مجلد `presentation/` في هذه الوحدة.
- تغيير القراءة أو الكتابة أو تكامل المنصة: ابدأ من مجلد `data/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
