# فهرس وحدات الميزات

كل مجلد هنا يمثل ميزة أو مجالًا من التطبيق. افتح الفهرس المحلي قبل تعديل ملفات الوحدة؛ وهو يشرح مسؤولية الملفات وروابطها. الروابط إلى الملفات نسبية إلى جذر المشروع.

| الميزة | المسؤولية المختصرة | فهرس الوحدة |
|---|---|---|
| التقارير والتحليلات (`analytics`) | جمع وعرض مؤشرات النشاط المحلي وتقارير المبيعات والمشتريات والمصروفات والديون والمخزون، مع فتح تفاصيل الفواتير وتصديرها عند الحاجة. | [`CODE_INDEX.md`](analytics/CODE_INDEX.md) |
| النسخ الاحتياطي والاستعادة (`backup`) | تصدير بيانات قاعدة المحل محليًا واستيراد نسخة احتياطية والتحقق منها قبل استبدال البيانات الحالية. | [`CODE_INDEX.md`](backup/CODE_INDEX.md) |
| الآلة الحاسبة (`calculator`) | آلة حاسبة داخل التطبيق؛ منطق تحليل التعبير الحسابي منفصل عن واجهة الاستخدام. | [`CODE_INDEX.md`](calculator/CODE_INDEX.md) |
| التواصل (`contact`) | واجهة معلومات/روابط التواصل المتاحة من داخل التطبيق. | [`CODE_INDEX.md`](contact/CODE_INDEX.md) |
| لوحة البداية (`dashboard`) | عرض ملخص سريع من بيانات المنتجات والمخزون عند فتح واجهة البداية. | [`CODE_INDEX.md`](dashboard/CODE_INDEX.md) |
| الديون والمدفوعات (`debts`) | عرض مستحقات العملاء والموردين وتسجيل مبالغ السداد عبر مستودعي المبيعات والمشتريات. | [`CODE_INDEX.md`](debts/CODE_INDEX.md) |
| المصروفات (`expenses`) | حفظ المصروفات المحلية وعرضها وتعديلها مع ملخص إجمالي. | [`CODE_INDEX.md`](expenses/CODE_INDEX.md) |
| المخزون (`inventory`) | استعراض حالة المخزون وحركاته وإجراء تسوية كمية من الواجهة. | [`CODE_INDEX.md`](inventory/CODE_INDEX.md) |
| المزيد (`more`) | تجميع مدخلات أو اختصارات إضافية ضمن واجهة التطبيق. | [`CODE_INDEX.md`](more/CODE_INDEX.md) |
| الملاحظات (`notes`) | حفظ الملاحظات المحلية وعرضها وتحريرها وإغلاقها. | [`CODE_INDEX.md`](notes/CODE_INDEX.md) |
| قراءة الفواتير OCR (`ocr`) | توفير خدمة تعرّف نصي تعمل محليًا مع تطبيقات منفصلة للمنصات المدعومة، وربطها بواجهة موحدة. | [`CODE_INDEX.md`](ocr/CODE_INDEX.md) |
| إنشاء PDF (`pdf`) | إنشاء مستندات PDF محلية مستخدمة من مسارات الفواتير والتقارير. | [`CODE_INDEX.md`](pdf/CODE_INDEX.md) |
| المنتجات (`products`) | إدارة بيانات المنتجات والبحث والأرشفة وأكوادها، وعرض القائمة والتفاصيل وإجراءات المخزون والبيع السريع. | [`CODE_INDEX.md`](products/CODE_INDEX.md) |
| المشتريات (`purchases`) | تسجيل فواتير الشراء وبنودها ومدفوعاتها، وتحديث بيانات المخزون والتكلفة من خلال المستودع. | [`CODE_INDEX.md`](purchases/CODE_INDEX.md) |
| المبيعات (`sales`) | إعداد فاتورة بيع وبنود السلة وتسجيلها محليًا مع بيانات الدفع. | [`CODE_INDEX.md`](sales/CODE_INDEX.md) |
| الماسح وربط الأكواد (`scanner`) | مسح باركود المنتج ثم ربط الرمز بمنتج موجود واستخدامه من مسارات التطبيق. | [`CODE_INDEX.md`](scanner/CODE_INDEX.md) |
| الإعدادات (`settings`) | قراءة وحفظ تفضيلات التطبيق المحلية. | [`CODE_INDEX.md`](settings/CODE_INDEX.md) |

## تقسيم الطبقات

- `presentation/`: واجهات الشاشة والنماذج والحوار.
- `domain/`: نماذج وقواعد أو حسابات خاصة بالميزة.
- `data/`: مستودعات/خدمات الوصول إلى البيانات أو إلى المنصة.

ليست كل ميزة تحتوي الطبقات الثلاث. لا تنشئ طبقات إضافية بلا حاجة؛ اتبع شكل الوحدة القائم.
