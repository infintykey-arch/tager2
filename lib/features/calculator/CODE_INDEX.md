# فهرس ميزة الآلة الحاسبة

**المجلد:** `lib/features/calculator/`

**الدور:** آلة حاسبة داخل التطبيق؛ منطق تحليل التعبير الحسابي منفصل عن واجهة الاستخدام.

## الملفات

- [`domain/calculator_engine.dart`](domain/calculator_engine.dart) — محرك تحليل وتقييم التعبيرات الحسابية.
- [`presentation/calculator_page.dart`](presentation/calculator_page.dart) — لوحة الآلة الحاسبة وعرض الإدخال والنتيجة.

## من أين أبدأ التعديل؟

- تغيير الشاشة أو التفاعل: ابدأ من مجلد `presentation/` في هذه الوحدة.
- تغيير نموذج أو قاعدة عمل: ابدأ من مجلد `domain/` في هذه الوحدة.

قبل التعديل، راجع الاختبارات المرتبطة بالميزة في [`test/features/`](../../../test/features/) ثم أضف/حدّث اختبارًا للسلوك الذي تغيّر.
