# فهرس طبقة التطبيق

**المجلد:** `lib/app/` — تكوين واجهة التطبيق وتجميع التنقل.

- [`tager_app.dart`](tager_app.dart) — إعداد الثيم واللغة وحالة المظهر، بناء هيكل التطبيق وقائمة التنقل، اختيار الصفحات وتمرير المستودعات إلى ميزاتها، والتعامل مع مسح أكواد المنتجات عند مستوى التطبيق.

**مسار العمل:** إذا أضفت صفحة جديدة فأنشئ واجهتها ضمن الوحدة المناسبة في `lib/features/`، ثم أضف ربطها/وجهتها هنا. تجنب وضع قواعد البيانات أو منطق التخزين داخل هيكل التنقل.
