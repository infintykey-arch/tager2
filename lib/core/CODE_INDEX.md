# فهرس الأدوات المشتركة

**المجلد:** `lib/core/` — وظائف ومكونات مشتركة بين ميزات متعددة.

- [`formatters.dart`](formatters.dart) — تنسيق القيم المشتركة المعروضة مثل المبالغ/الأرقام حسب الاستخدام في التطبيق.
- [`payment_snapshot.dart`](payment_snapshot.dart) — قيمة/لقطة موحدة لبيانات الدفع تستخدمها مسارات مثل المبيعات والمشتريات والتقارير والديون.
- [`ads/CODE_INDEX.md`](ads/CODE_INDEX.md) — إعداد وتشغيل عناصر الإعلانات.

قبل إضافة أداة مشتركة، تأكد أن لها أكثر من مستهلك وأنها لا تنتمي بوضوح إلى ميزة واحدة.
