# فهرس قاعدة البيانات المحلية

**المجلد:** `lib/data/local/` — قاعدة Drift وتخزين التطبيق المحلي.

- [`app_database.dart`](app_database.dart) — جداول المنتجات والحركات والعملاء والمبيعات والموردين والمشتريات والمصروفات والملاحظات والتفضيلات، إصدار المخطط، الترحيلات، والفهارس/الملخصات المحسّنة. تحقق من تعريفات هذا الملف قبل تعديل المخطط.
- [`app_database.g.dart`](app_database.g.dart) — شيفرة Drift مولّدة؛ **لا تعدّلها يدويًا**. بعد تعديل المصدر استخدم أداة التوليد المحددة لاعتماديات المشروع ثم راجع التغيير الناتج.

أي تغيير في جدول يحتاج مراجعة ترحيل قاعدة البيانات واختبارات الاستمرارية/الترحيل في [`test/data/local/`](../../../test/data/local/). افحص مستودعات الميزات التي تقرأ الجدول نفسه قبل إتمام التغيير.
