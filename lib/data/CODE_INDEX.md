# فهرس طبقة البيانات

**المجلد:** `lib/data/` — التخزين المحلي المشترك الذي تعتمد عليه مستودعات الميزات.

- [`local/CODE_INDEX.md`](local/CODE_INDEX.md) — قاعدة البيانات المحلية ومخططها والترحيلات وملفات Drift المولّدة.

عمليات كل مجال تبقى غالبًا في مستودع الميزة داخل `lib/features/<feature>/data/`، بينما هذا المجلد يملك القاعدة والجداول المشتركة.
