# فهرس سكربتات التطوير والبناء

**المجلد:** `scripts/` — إجراءات مساعدة محدودة لبناء وتجهيز نسخة الويب.

- [`build_local_web.sh`](build_local_web.sh) — يبني إصدار Flutter Web مع موارد محلية، ينشئ قائمة الموارد المسبقة، ثم يزيل عامل Flutter الافتراضي بحسب إعداد المشروع.
- [`create_web_precache_manifest.py`](create_web_precache_manifest.py) — ينشئ بيان موارد التحميل المسبق من مخرجات البناء.

شغّل السكربت من أي مجلد؛ فهو يحدد جذر المشروع من موقع الملف. لا تضع أسرار أو بيانات مستخدمين ضمن هذه الأدوات.
