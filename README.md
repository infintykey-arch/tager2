# تاجر ٢ (Tager 2)

تطبيق Android مستقل لإدارة المنتجات والمخزون للمحلات الصغيرة. الإصدار الأول عربي بالكامل، يعمل محليًا دون تسجيل دخول أو اتصال بخادم.

## ما يعمل حاليًا

- إضافة المنتجات وتعديلها وأرشفتها.
- حفظ الأسعار كقروش صحيحة وعرضها بالجنيه المصري.
- تسجيل الرصيد الافتتاحي وتسويات المخزون في سجل حركات موثق.
- البحث والتنبيه عند بلوغ حد المخزون.
- عرض سجل الحركات والملخص المحلي.

المبيعات، العملاء، المشتريات، المصروفات، المرتجعات، التقارير، والنسخ الاحتياطي ما زالت ضمن مراحل التطوير؛ قواعد التكلفة والعمليات المالية لم تُعتمد بعد.

## تشغيل المشروع

يتطلب Flutter SDK مع Android SDK. بعد تثبيت المتطلبات:

```bash
flutter pub get
flutter run
```

لتشغيل الاختبارات:

```bash
flutter test
```

لبناء APK تجريبي:

```bash
flutter build apk --debug
```

## توقيع إصدار Android

معرف التطبيق المختار لهذا المستودع هو `com.infintykey.tager2`. لا تتوفر هنا بيانات معرف التطبيق السابق لمقارنته؛ يلزم التأكد من اختلاف المعرفين قبل تثبيت التطبيقين جنبًا إلى جنب، لأن مفتاح التوقيع المختلف وحده لا يحقق ذلك. يحتفظ إعداد Gradle ببيانات التوقيع في متغيرات بيئة وقت البناء فقط؛ لا تضع المفتاح أو كلمات المرور في ملفات المشروع أو Git. ملفات `*.jks` و`*.keystore` و`*.p12` و`android/key.properties` مستبعدة من Git.

قبل بناء Release، وفّر المتغيرات `TAGER2_KEYSTORE_PATH` و`TAGER2_KEY_ALIAS` و`TAGER2_STORE_PASSWORD` و`TAGER2_KEY_PASSWORD` في بيئة البناء. يرفض Gradle بناء Release عند غيابها، ولا يستخدم مفتاح debug كتوقيع إصدار.
