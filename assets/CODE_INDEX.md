# فهرس الأصول

**المجلد:** `assets/` — ملفات ثابتة يضمّنها التطبيق أو يرجع إليها وقت التشغيل.

- `fonts/` — خط عربي وخط لاتيني مستخدمان في واجهات/PDF حسب التكوين.
- `images/` — صور ثابتة مثل شعار التطبيق.
- `tessdata/` و[`tessdata_config.json`](tessdata_config.json) — بيانات لغات OCR وإعداداتها.
- [`admob_ids.json`](admob_ids.json) — إعداد معرفات وحدات الإعلانات المقروءة من الكود. لا تنسخ معرفات إعلانية إلى مكان آخر؛ عدّل المصدر المركزي وفق سياسة المشروع.
- `licenses/` — تراخيص خطوط ومكتبات وبيانات مضمّنة. احتفظ بالتراخيص عند تحديث الأصول المورّدة.

الأصول المضمّنة وقائمة الملفات المسموح بها موضحة في [`../pubspec.yaml`](../pubspec.yaml).
